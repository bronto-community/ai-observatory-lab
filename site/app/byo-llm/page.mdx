# Use your own OpenAI, Anthropic or Google key

Both labs can call a model from OpenAI, Anthropic or Google directly instead of Amazon Bedrock: no AWS account or
AWS CLI needed. [Start here](/start) sets it up when you pick **Your own API key**. This page is the reference.

| Provider | `.env` lines | Default model | Get a key |
|---|---|---|---|
| OpenAI | `LLM_PROVIDER=openai`<br/>`OPENAI_API_KEY=sk-…` | `gpt-5.4-mini` | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) |
| Anthropic | `LLM_PROVIDER=anthropic`<br/>`ANTHROPIC_API_KEY=sk-ant-…` | `claude-haiku-4-5-20251001` | [console.anthropic.com](https://console.anthropic.com/settings/keys) |
| Google | `LLM_PROVIDER=gemini`<br/>`GEMINI_API_KEY=…` | `gemini-3.8-flash` | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |

- **A different model** from the same provider: add `MODEL_ID=…` (for example `MODEL_ID=gpt-5.4`). In Track A, a
  request can also switch it for one question with `"model": "…"` (step 9).
- **The traces look the same.** Strands emits the same GenAI spans for every provider, so the Bronto views and the
  Track A dashboard keep working. Only the finish-reasons widget stays empty: on Bedrock that comes from the AWS
  SDK's own span.
- **Track B** runs Severin's agent code unchanged. The `track-b-agent` images add only this provider switch on top
  of his images.
- **Cost estimate:** the Track A stats estimate cost from list prices on file. For models without one (including
  `gpt-5.4-mini` and `gemini-3.8-flash`), it shows `null`. The token counts are still exact.
- **To go back to Bedrock**, delete the two lines (or set `LLM_PROVIDER=bedrock`) and follow the AWS route in
  [Start here](/start).

<Callout tone="warn" title="Keep your key out of anything you share">
Your `.env` holds a secret: don't commit it or paste it anywhere public. Your key is billed by the provider, not by
AWS, so the AWS credits don't apply.
</Callout>
